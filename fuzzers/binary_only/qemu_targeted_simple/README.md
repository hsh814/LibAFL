# qemu_targeted_simple
A simple fuzzer that runs a binary in qemu. Generate test cases and save them to the output directory when the execution reaches the specified target address.
    

## Usage
```bash
cargo build --release
./target/release/qemu_targeted_simple --input /path/to/poc/input --target-loc 0x456845 --output out ./nm.orig -- -l @@
```
- `--input` specifies the path to the input file that will be used as an argument for the guest binary.
- `--output` specifies the directory where the generated test cases will be saved.
 - `out/seeds`: contains the generated seeds
 - `out/reached`: contains the test cases that reached the target address
- `--target-loc` specifies the address of the instruction to be targeted in the guest binary.
- `./nm.orig` is the path to the original guest binary that will be executed in qemu.
- `-l @@` are the options that will be passed to the guest binary. The `@@` will be replaced with the path to the test case file generated by the fuzzer.
